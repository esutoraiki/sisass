img-remplace (_base.scscs)

Tipo: Mixin

Versión: 2.x.x

Reemplaza texto visual por una imagen de fondo, manteniendo el contenido textual en el marcado.

Aplica utilidades de fondo, tamaño, ocultamiento de texto y control de display en una sola llamada.

Interface 

@mixin img-remplace($image, $iw: auto, $ih: auto, $display: block);

Sintaxis alternativa (map) 

@include img-remplace((
    image: "",
    url: "",
    i: "",
    u: "",
    width: auto,
    w: auto,
    height: auto,
    h: auto,
    display: block,
    d: block,
    repeat: no-repeat,
    r: no-repeat,
    position: center,
    p: center,
    color: transparent,
    c: transparent,
    size: cover,
    s: cover
));

Valores por defecto: iw: auto, ih: auto, display: block, repeat: no-repeat, position: center, color: transparent, size: cover.

Parametro Tipo Default Descripcion
$image String | Map Requerido Ruta de imagen o map. Si es map, habilita claves y aliases de imagen, medidas, display y background.
$iw Medida auto Ancho del elemento cuando se usa sintaxis posicional.
$ih Medida auto Alto del elemento cuando se usa sintaxis posicional.
$display String block Define el valor de display del elemento.
image | url | i | u (map) String "" Ruta de la imagen de fondo. Prioridad de lectura: image, luego url, luego i, luego u.
width | w (map) Medida auto Ancho del elemento cuando se usa sintaxis map.
height | h (map) Medida auto Alto del elemento cuando se usa sintaxis map.
display | d (map) String block Valor de display aplicado al elemento.
repeat | r (map) String no-repeat Valor de background-repeat.
position | p (map) String center Valor de background-position.
color | c (map) Color transparent Valor de background-color.
size | s (map) String cover Valor de background-size.

Nota: en modo map, los aliases cortos solo se usan si no existe su clave larga equivalente.
