gap (_base.scscs)

Tipo: Mixin

Versión: 2.x.x

Define la separación entre elementos hijos en contenedores flex o grid.

El mixin escribe grid-gap y gap para mantener compatibilidad, pero no define el tipo de layout del contenedor.

Interface 

@mixin gap($value);

Sin valor por defecto: debes enviar la separación a aplicar.

Parámetros secuenciales

Parámetro Tipo Default Descripción
value Medida | Lista Requerido Define el valor de gap y grid-gap. Acepta un valor o dos valores (fila/columna).

Ejemplo 


            


            

                

            


            

                
<div class="gap_example">
    <div class="box"></div>
    <div class="box"></div>
    <div class="box"></div>
</div>
