gap (_base.scscs)

Tipo: Mixin

Versión: 2.x.x

Define la separacion entre elementos hijos en contenedores flex o grid.

El mixin escribe grid-gap y gap para mantener compatibilidad, pero no define el tipo de layout del contenedor.

Interface 

@mixin gap($value);

Sin valor por defecto: debes enviar la separacion a aplicar.

Parametro Tipo Default Descripcion
$value Medida | Lista Requerido Define el valor de gap y grid-gap. Acepta un valor o dos valores (fila/columna).
