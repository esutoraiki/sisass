cover (_base.scscs)

Tipo: Mixin

Versión: 2.x.x

Ajusta el contenido para cubrir por completo su contenedor usando object-fit: cover.

Internamente también aplica width: 100% y height: 100% mediante whs(100%), por lo que el elemento ocupa todo el espacio disponible antes de aplicar el recorte visual.

Interface 

@mixin cover;

Ejemplo

</div>
