background (_base.scscs)

Tipo: Mixin

Versión: 2.x.x

Normaliza los estilos para las propiedades referentes al background. Puedes usarlo para aplicar colores, imagenes de fondo o gradientes. El atributo url genera un background-image con url(), mientras que image permite pasar cualquier valor valido de background-image (por ejemplo, gradients o imagenes inline).

Tambien puedes controlar repeticion, posicion y size del background con las claves disponibles en el map.

Interface 

@mixin background($attr: (
    url: "",
    repeat: no-repeat,
    position: center,
    color: transparent,
    size: auto,
    image: ""
);

Atributos

Clave Tipo Default Descripción
url String "" Valor a utilizar en la función url con background-image.
repeat String no-repeat Valor a utilizar con background-repeat.
position String center Valor a utilizar con background-position.
color Color transparent Valor a utilizar con background-color.
size String auto Valor a utilizar con background-size.
image String "" Valor a utilizar con background-image.
