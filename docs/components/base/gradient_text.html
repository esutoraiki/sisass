gradient-text (_base.scscs)

Tipo: Mixin

Versión: 2.x.x

Aplica un gradiente al texto. El parametro recibe los argumentos de linear-gradient, no la funcion completa.

Interface 

@mixin gradient-text($grad);
Parámetro Tipo Descripción
$grad String | List Argumentos para linear-gradient (ej: (90deg, #A01303, #2D396C)).
