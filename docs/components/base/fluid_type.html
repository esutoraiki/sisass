fluid-type (_base.scscs)

Tipo: Mixin

Versión: 2.x.x

Genera tipografía fluida entre dos tamaños.

Interface 

@mixin fluid-type($attr: ());

Valores por defecto: mins 320px, maxs 1920px, minv 14px, maxv 24px, attr font-size.

Parámetro Tipo Descripción
$attr Map Configuración responsive.
