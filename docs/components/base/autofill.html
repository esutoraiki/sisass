autofill (_base.scscs)

Tipo: Mixin

Versión: 2.x.x

Permite definir estilos para el estado autofill en inputs (WebKit).

Interface 

@mixin autofill($background, $color);

background: Color de fondo aplicado al autofill.

color: Color del texto aplicado al autofill.
