icon-svg (_base.scscs)

Tipo: Mixin

Versión: 2.x.x

Inserta un SVG como background (requiere postcss-inline-svg).

Interface 

@mixin icon-svg($svg, $w, $h, $fill: "none", $def: "none");

Valores por defecto: fill "none", def "none".

Parámetro Tipo Descripción
$svg String Nombre del SVG.
$w Medida Ancho.
$h Medida Alto.
$fill String Color o modo de relleno.
$def String SVG inline cuando fill es inline.
