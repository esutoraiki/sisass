resolve-size (_base.scss)

Tipo: Mixin

Versión: 2.x.x

Resuelve dos dimensiones compatibles entre width, height y aspect_ratio. Requiere exactamente una de estas combinaciones: ancho y alto, ancho y relación, o alto y relación.

El mixin recibe un mapa y admite los alias documentados. Si se envía una combinación incompleta o las tres dimensiones, genera un error.

Interface

@mixin resolve-size($attr: ());

Sintaxis map

Clave Tipo Default Descripción
width | wMedidanullDefine la propiedad width cuando forma parte de una combinación válida.
height | hMedidanullDefine la propiedad height cuando forma parte de una combinación válida.
aspect_ratio | ratio | rNumbernullDefine la propiedad CSS aspect-ratio cuando forma parte de una combinación válida.

Ejemplo

Los tres elementos obtienen el mismo ancho y alto final mediante tres combinaciones diferentes: el primero recibe width y height, el segundo recibe width y aspect_ratio, y el tercero recibe height y aspect_ratio. El resultado permite comprobar que resolve-size calcula las dimensiones equivalentes a partir de cualquiera de esas parejas válidas.

width + height
width + ratio
height + ratio
