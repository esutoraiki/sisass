font-face (_base.scscs)

Tipo: Mixin

Version: 2.x.x

Declara un @font-face mediante un map de atributos. Requiere name y path, y permite configurar weight, style, display y exts.

Por defecto usa extensiones woff2, woff y ttf. Si necesitas compatibilidad adicional, puedes agregar eot o svg de forma opcional en la lista exts.

Valores recomendados: weight acepta valores como normal, bold o numericos (100 a 900); style acepta normal, italic u oblique; display acepta auto, block, swap, fallback y optional.

Interface 

@mixin font-face($attr: (
    name: null,
    path: null,
    weight: normal,
    style: normal,
    display: swap,
    exts: (woff2, woff, ttf)
);

Valores por defecto: weight normal, style normal, display swap, exts (woff2, woff, ttf).

Clave Tipo Default Descripcion
name String null Nombre de la familia tipografica para font-family.
path String null Ruta base del archivo sin extension.
weight String | Number normal Define font-weight dentro de @font-face.
style String normal Define font-style dentro de @font-face.
display String swap Define font-display dentro de @font-face.
exts List (woff2, woff, ttf) Lista de extensiones a generar. eot y svg son opcionales.
