font-face (_base.scscs)

Tipo: Mixin

Versión: 2.x.x

Declara un @font-face con múltiples formatos.

Interface 

@mixin font-face($name, $path, $weight: null, $style: null, $exts: eot woff2 woff ttf svg);

Valores por defecto: weight null, style null, exts eot woff2 woff ttf svg.

Parámetro Tipo Descripción
$name String Nombre de la fuente.
$path String Ruta base sin extensión.
$weight String | Number Peso.
$style String Estilo.
$exts List Extensiones.
