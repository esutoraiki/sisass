background-opacity (_base.scscs)

Tipo: Mixin

Versión: 2.x.x

Genera un background con opacidad usando sintaxis moderna o rgba. Soporta dos formas de uso: parametros individuales o un map con las claves color, opacity y use_legacy.

Interface 

@mixin background-opacity($color: #FFF, $opacity: 0.8, $use_legacy: false);

Sintaxis alternativa (map) 

@include background-opacity((
    color: #FFF,
    opacity: 0.8,
    use_legacy: false
));

Valores por defecto: #FFF, 0.8, false.

Parámetro Tipo Default Descripción
$color Color | Map #FFF Si es color, define el color base. Si es map, puede incluir color, opacity y use_legacy.
$opacity Number 0.8 Define la opacidad cuando el primer parametro no es map.
$use_legacy Bool false Usar rgba como fallback cuando el primer parametro no es map.
