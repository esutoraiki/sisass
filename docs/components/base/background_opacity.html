background-opacity (_base.scscs)

Tipo: Mixin

Versión: 2.x.x

Genera un background con opacidad usando rgba.

Interface 

@mixin background-opacity($color: #FFF, $opacity: 0.8);

Valores por defecto: #FFF, 0.8.

Parámetro Tipo Default Descripción
$color Color #FFF Color base.
$opacity Number 0.8 Opacidad.
