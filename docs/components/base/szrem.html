szrem (_base.scscs)

Tipo: Function

Versión: 2.x.x

Convierte un valor en píxeles a rem a partir de una base configurable.

Es útil para normalizar escalas tipográficas y de espaciado cuando el proyecto trabaja con unidades relativas.

La función recibe dos parámetros porque el cálculo necesita tanto el valor a convertir como la base de referencia. value_px representa la medida original en píxeles y base representa el tamaño base sobre el que se calcula 1rem. El resultado se obtiene dividiendo value_px entre base y multiplicando ese cociente por 1rem. Por ejemplo, szrem(24, 16) devuelve 1.5rem.

Interface 

@function szrem($value_px: 14, $base: 16);

Parámetros secuenciales

Parámetro Tipo Default Descripción
value_px Number 14 Define el valor en píxeles que se convertirá a rem.
base Number 16 Define la base usada para calcular la equivalencia en rem.
