no-spacing (_base.scscs)

Tipo: Mixin

Versión: 2.x.x

Resetea los márgenes y los paddings del elemento, dejando todos sus lados en 0.

Es un helper de reset útil para normalizar el espaciado base antes de aplicar una composición o un componente.

Interface 

@mixin no-spacing;

Ejemplo

Sin márgenes ni padding
