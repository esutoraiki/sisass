bc (_base.scscs)

Tipo: Mixin

Versión: 2.x.x

Aplica background-color y color en una sola llamada.

Interface 

@mixin bc($background: #FFF, $color: #000);

Valores por defecto: #FFF, #000.

Parámetro Tipo Default Descripción
$background Color #FFF Color de fondo.
$color Color #000 Color del texto.
