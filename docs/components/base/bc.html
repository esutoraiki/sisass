bc (_base.scscs)

Tipo: Mixin

Versión: 2.x.x

Aplica background-color y color en una sola llamada. Es un atajo útil para definir el color de fondo y el color del texto sobre el mismo selector.

Interface 

@mixin bc($background: #FFF, $color: #000);

Valores por defecto: #FFF, #000.

Parámetros secuenciales

Parámetro Tipo Default Descripción
background Color #FFF Define la propiedad background-color.
color Color #000 Define la propiedad color.
