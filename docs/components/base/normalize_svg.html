normalize-svg (_base.scscs)

Tipo: Mixin

Versión: 2.x.x

Normaliza estilos para elementos que representen un recurso SVG dentro de la interfaz.

Es un wrapper especializado sobre replace-base para el flujo de SVG. Su valor está en ofrecer una configuración predeterminada útil para trabajar junto a icon-svg, y el bloque position se resuelve con el mixin position.

Interface 

@mixin normalize-svg($attr: (
    width: auto,
    height: auto,
    position: (
        position: relative,
        y: 0,
        x: 0,
        yaxis: top,
        xaxis: left,
        top: null,
        right: null,
        bottom: null,
        left: null,
        z: 2
    ),
    display: block,
    ht: true
));

Equivale a usar replace-base con position: (position: relative, z: 2), display: block y ht: true como valores base. Las opciones de posición se configuran dentro del map anidado de position, y sus valores predeterminados se conservan al sobrescribir solo una clave.

Sintaxis map

Clave Tipo Default Descripción
width | w Medida auto Define la propiedad width.
height | h Medida auto Define la propiedad height.
position | p Map (position: relative, z: 2) Configura la posición mediante un map anidado con la sintaxis del mixin position.
position.position | position.p String relative Define la propiedad position dentro del map anidado.
position.y Medida 0 Define el desplazamiento vertical dentro del map de position.
position.x Medida 0 Define el desplazamiento horizontal dentro del map de position.
position.yaxis | position.ya String top Define la propiedad CSS usada para el eje Y dentro del map de position.
position.xaxis | position.xa String left Define la propiedad CSS usada para el eje X dentro del map de position.
position.top | position.t Medida | Null null Define la propiedad top dentro del map de position.
position.right | position.r Medida | Null null Define la propiedad right dentro del map de position.
position.bottom | position.b Medida | Null null Define la propiedad bottom dentro del map de position.
position.left | position.l Medida | Null null Define la propiedad left dentro del map de position.
position.z Number 2 Define z-index dentro del map de position.
display | d String block Define la propiedad display.
ht Bool true Controla si se aplica el mixin ht para ocultar el texto.
