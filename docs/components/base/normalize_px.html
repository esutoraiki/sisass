normalize-px (_base.scscs)

Tipo: Function

Versión: 2.x.x

Normaliza un valor para que use px cuando llega sin unidad y conserve el valor original cuando ya la incluye.

Por ejemplo, si pasas 220, la función devuelve 220px; si pasas 220px, lo deja igual; y si pasas auto, también lo deja igual. Así puedes escribir valores sin unidad y obtener una medida en px automáticamente, sin alterar palabras clave como auto, inherit, max-content, ....

Interface 

@function normalize-px($value);

Parámetros secuenciales

Parámetro Tipo Default Descripción
value Number | Medida - Define el valor que se normaliza a px si llega sin unidad.
