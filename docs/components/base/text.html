text (_base.scscs)

Tipo: Mixin

Version: 2.x.x

Permite configurar alineacion, transformacion, decoracion y wrap de texto. Ahora soporta dos formas de uso: pasando parametros individuales o un mapa con las claves align, transform, decoration y wrap.

Interface 

@mixin text($aling: left, $trans: initial, $decor: initial, $wrap: initial);

Sintaxis alternativa (map) 

@include text((
    align: left,
    transform: initial,
    decoration: initial,
    wrap: initial
));

Valores por defecto: left, initial, initial, initial.

Parametro Tipo Default Descripcion
$aling String | Map left Si es string, define text-align. Si es map, puede incluir align, transform, decoration, wrap.
$trans String initial Define text-transform cuando el primer parametro no es map.
$decor String initial Define text-decoration cuando el primer parametro no es map.
$wrap String initial Define text-wrap cuando el primer parametro no es map.
