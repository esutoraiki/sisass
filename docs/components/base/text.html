text (_base.scscs)

Tipo: Mixin

Versión: 2.x.x

Permite configurar alineación, transformación y decoración de texto. Ahora soporta dos formas de uso: pasando parámetros individuales o un mapa con las claves align, transform y decoration.

Interface 

@mixin text($aling: left, $trans: none, $decor: none);

Valores por defecto: left, none, none.

Parámetro Tipo Descripción
$aling String | Map Si es string, define text-align. Si es map, puede incluir align, transform, decoration.
$trans String Define text-transform cuando el primer parámetro no es map.
$decor String Define text-decoration cuando el primer parámetro no es map.
