text (_base.scscs)

Tipo: Mixin

Versión: 2.x.x

Permite configurar alineación, transformación, decoración y wrap de texto. Ahora soporta dos formas de uso: pasando parámetros individuales o un mapa con las claves align | a, decoration | d, transform | t y wrap | wr.

Interface 

@mixin text($align: left, $trans: initial, $decor: initial, $wrap: initial);

Sintaxis alternativa (map) 

@include text((
    align: left,
    decoration: initial,
    transform: initial,
    wrap: initial
));

Parámetros secuenciales

Parámetro Tipo Default Descripción
align String left Define la propiedad text-align.
trans String initial Define la propiedad text-transform.
decor String initial Define la propiedad text-decoration.
wrap String initial Define la propiedad text-wrap.

Sintaxis map

Clave Tipo Default Descripción
align | a String left Define la propiedad text-align.
decoration | d String initial Define la propiedad text-decoration.
transform | t String initial Define la propiedad text-transform.
wrap | wr String initial Define la propiedad text-wrap.
