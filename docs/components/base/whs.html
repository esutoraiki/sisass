whs (_base.scscs)

Tipo: Mixin

Versión: 2.x.x

Asigna width y height con el mismo valor. Es útil para definir dimensiones cuadradas o mantener ambas medidas sincronizadas con una sola entrada.

Interface 

@mixin whs($value_aa: auto);

Valor por defecto: auto.

Parámetros secuenciales

Parámetro Tipo Default Descripción
value_aa Medida auto Define las propiedades width y height con el mismo valor.
