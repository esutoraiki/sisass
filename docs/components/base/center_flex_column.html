center-flex-column (_base.scscs)

Tipo: Mixin

Versión: 2.x.x

Convierte el contenedor en un layout flex con dirección de columna y centra sus hijos en ambos ejes.

Internamente aplica flex-direction: column, habilita display: flex y usa place-content: center junto con place-items: center para alinear el contenido.

Interface 

@mixin center-flex-column;

Ejemplo 


            


            

                

            


            

                
<div class="center_flex_column_demo">
    <div class="box"></div>
    <div class="box"></div>
</div>
