no-border (_base.scscs)

Tipo: Mixin

Versión: 2.x.x

Elimina los bordes del elemento, dejando todos sus lados en 0 none transparent.

Es un helper de reset útil para neutralizar estilos heredados o preparar una base visual sin bordes.

Interface 

@mixin no-border;
