font (_base.scscs)

Tipo: Mixin

Version: 2.x.x

Permite configurar propiedades de tipografia como tamano, familia, peso, estilo, line-height y variant. Ahora soporta dos formas de uso: pasando parametros individuales o un mapa con las claves size, family, weight, style, line-height y variant.

Interface 

@mixin font($size: 1em, $family: "sans-serif", $weight: normal, $style: normal, $line-height: "none", $variant: normal);

Valores por defecto: 1em, "sans-serif", normal, normal, "none", normal.

Parametro Tipo Default Descripcion
$size String | Map 1em Si es string, define font-size. Si es map, puede incluir size, family, weight, style, line-height, variant.
$family String "sans-serif" Define font-family cuando el primer parametro no es map.
$weight String | Number normal Define font-weight cuando el primer parametro no es map.
$style String normal Define font-style cuando el primer parametro no es map.
$line-height String | Number "none" Define line-height cuando el primer parametro no es map.
$variant String normal Define font-variant cuando el primer parametro no es map.
