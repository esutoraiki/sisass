icon_svg_mask (_base.scscs)

Tipo: Mixin

Versión: 2.x.x

Aplica un SVG como mascara CSS y colorea el resultado con background-color.

Requiere postcss-inline-svg porque utiliza svg-load() para construir mask-image.

Interface 

@mixin icon_svg_mask($attr: (
    svg: false,
    color: $c1,
    position: absolute,
    x: 0,
    y: 0,
    xaxis: left,
    yaxis: top,
    width: 100px,
    height: 100px,
    repeat: no-repeat,
    size: contain,
    path: $i1,
    display: block
));

Valores por defecto: color $c1, position absolute, x 0, y 0, xaxis left, yaxis top, width 100px, height 100px, repeat no-repeat, size contain, path $i1, display block.

Clave Tipo Default Descripcion
svg String | Bool false Nombre base del archivo SVG. Si es false no genera la mascara.
color Color $c1 Define el color final del icono mediante background-color.
position String | Bool absolute Tipo de posicionamiento usado por el mixin position(). Si es false no aplica posicionamiento.
x Medida 0 Desplazamiento horizontal aplicado por position().
y Medida 0 Desplazamiento vertical aplicado por position().
xaxis String left Eje horizontal usado por position().
yaxis String top Eje vertical usado por position().
width Medida 100px Asigna el ancho del area visible del icono.
height Medida 100px Asigna el alto del area visible del icono.
repeat String no-repeat Controla la repeticion de la mascara.
size String | Medida contain Controla el escalado de la mascara SVG.
path String $i1 Prefijo de ruta donde se busca el archivo SVG.
display String block Define el valor de display del elemento.
