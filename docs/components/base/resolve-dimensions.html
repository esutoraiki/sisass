resolve-dimensions (_base.scss)

Tipo: Function

Versión: 2.x.x

Recibe un ancho y un alto de referencia, calcula su relación de aspecto y devuelve un nuevo par de dimensiones cuando se determina el ancho o el alto esperado.

La función devuelve un mapa con las claves width y height.

Para consumir el resultado, usa map.get($dimensions, width) y map.get($dimensions, height), donde $dimensions contiene el mapa devuelto por la función.

Interface 

@function resolve-dimensions($attr: ());

Sintaxis map

Clave Tipo Default Descripción
width | w Number null Define el ancho base usado para obtener la proporción.
height | h Number null Define el alto base usado para obtener la proporción.
seed_width | sw Number null Establece el ancho final y calcula el alto conservando la proporción.
seed_height | sh Number null Establece el alto final y calcula el ancho conservando la proporción.

width y height son obligatorios. Si se envían seed_width y seed_height al mismo tiempo, la función genera un error.

Ejemplo

Las dimensiones de referencia son 160px × 90px. Al establecer seed_width: 320px, la función devuelve width: 320px y height: 180px, conservando la relación de aspecto definida por las dimensiones de referencia.
