contain (_base.scscs)

Tipo: Mixin

Versión: 2.x.x

Ajusta el contenido para mantenerse completo dentro de su contenedor usando object-fit: contain.

Internamente también aplica width: 100% y height: 100% mediante whs(100%), por lo que el elemento ocupa todo el espacio disponible antes de calcular el ajuste visual.

Interface 

@mixin contain;
