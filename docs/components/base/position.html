position (_base.scscs)

Tipo: Mixin

Versión: 2.x.x

Define el valor de position y aplica offsets usando dos formas: sintaxis por ejes (y/x) o sintaxis explicita por lados (top/right/bottom/left) con aliases cortos (t/r/b/l).

La sintaxis y/x es compacta para ajustes rapidos: $y controla el eje vertical y $x el horizontal; $yaxis y $xaxis indican que propiedad CSS usa cada eje (por ejemplo, top/left o bottom/right).

El mixin esta diseñado a propósito con el eje Y primero porque, en escenarios reales, suele modificarse solo top. Cuando necesitas control puntual por cada lado, usa la sintaxis explicita en map para declarar top, right, bottom y left (o sus aliases t, r, b, l).

Interface 

@mixin position($position: relative, $y: 0, $x: 0, $yaxis: top, $xaxis: left);

Sintaxis alternativa (map) 

@include position((
    position: relative,
    y: 0,
    x: 0,
    yaxis: top,
    xaxis: left,
    top: null,
    right: null,
    bottom: null,
    left: null,
    t: null,
    r: null,
    b: null,
    l: null
));

Uso recomendado de map: define position y luego elige una sola estrategia. Si incluyes top/right/bottom/left o t/r/b/l, se usa sintaxis explicita; si no, se aplica la sintaxis por ejes y/x.

Valores por defecto: relative, y: 0, x: 0, yaxis: top, xaxis: left, top/right/bottom/left: null, t/r/b/l: null.

Parametro Tipo Default Descripcion
$position String | Map relative Define la propiedad position. Tambien puede recibir un map con claves de ejes y lados.
$y Medida 0 Define el valor del offset para el eje Y cuando no se usa un lado explicito.
$x Medida 0 Define el valor del offset para el eje X cuando no se usa un lado explicito.
$yaxis String top Selecciona la propiedad CSS del eje Y (por ejemplo: top o bottom).
$xaxis String left Selecciona la propiedad CSS del eje X (por ejemplo: left o right).
top Medida | Null null Asigna top de forma explicita cuando se usa map. Alias: t.
right Medida | Null null Asigna right de forma explicita cuando se usa map. Alias: r.
bottom Medida | Null null Asigna bottom de forma explicita cuando se usa map. Alias: b.
left Medida | Null null Asigna left de forma explicita cuando se usa map. Alias: l.

Precedencia: si el map incluye top, right, bottom o left (o sus aliases), esos lados se aplican primero y reemplazan la salida basada en y/x. Si se define clave larga y alias al mismo tiempo, prevalece la clave larga.
