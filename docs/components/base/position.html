position (_base.scscs)

Tipo: Mixin

Versión: 2.x.x

Asigna position y los offsets correspondientes.

Interface 

@mixin position($position: relative, $value_1: 0, $value_2: 0, $posit_1: top, $posit_2: left);

Valores por defecto: relative, 0, 0, top, left.

Parámetro Tipo Descripción
$position String Tipo de posicionamiento.
$value_1 Medida Valor para el primer eje.
$value_2 Medida Valor para el segundo eje.
$posit_1 String Propiedad del primer eje.
$posit_2 String Propiedad del segundo eje.
