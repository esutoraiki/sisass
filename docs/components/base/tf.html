tf (_base.scscs)

Tipo: Mixin

Version: 2.x.x

Mixin combinado para texto y tipografia. Usa los mismos defaults de text y font, pero recibe un solo map con todas las claves.

Interface 

@mixin tf($attr: (
    align: left,
    transform: initial,
    decoration: initial,
    size: 1em,
    family: "sans-serif",
    weight: normal,
    style: normal,
    line-height: "none",
    variant: normal
);
Clave Tipo Default Descripcion
align String left Define text-align.
transform String initial Define text-transform.
decoration String initial Define text-decoration.
size String 1em Define font-size.
family String "sans-serif" Define font-family.
weight String | Number normal Define font-weight.
style String normal Define font-style.
line-height String | Number "none" Define line-height.
variant String normal Define font-variant.
