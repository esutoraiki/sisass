_buttons.scss (archivo)

Tipo: Referencia

Versión: 2.x.x

src/sisass_components/_buttons.scss reúne mixins para construir botones configurables mediante mapas. Incluye una base sencilla y dos variantes visuales con estados interactivos y estructura interna específica.

Cada mixin permite adaptar dimensiones, tipografía, colores y bordes sin duplicar su implementación. Las variantes estilizadas añaden composición visual mediante pseudoelementos y el nodo interno .content_link.

Clasificación de mixins

Categoría Mixins
Botones básicos button_simple
Botones estilizados button_style_adidas_1, button_bisel
