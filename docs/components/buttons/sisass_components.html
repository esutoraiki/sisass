sisass_components (directorio)

En src/sisass_components se encuentran los mixins de componentes disponibles en SISASS. Estos recursos agrupan piezas de interfaz reutilizables, como botones. Para usarlos, importa el módulo del grupo de componentes en tu archivo SCSS y llama el mixin dentro del selector que recibirá el estilo. 

@use "sisass_components/buttons" as *;

.button_primary {
    @include button_simple(
        (
            bg: #FFF,
            c: #000,
            bgh: #000,
            ch: #FFF
        )
    );
}

Nota: Los archivos de src/sisass_components pertenecen al framework y no deben editarse desde un proyecto consumidor. Para personalizar un componente, usa sus parámetros desde tu propio archivo SCSS.
