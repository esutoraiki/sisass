button_style_arrow (_buttons.scss)

Tipo: Mixin

Versión: 2.x.x

Crea un botón con doble contorno y desplaza el plano posterior durante :hover. Permite elegir una flecha a la izquierda o a la derecha, con dirección derecha por defecto, y dispone de estilos para .active, :disabled y .disabled.

El botón debe contener un elemento .content_link. El mixin aplica a ese nodo el contenido visual, la tipografía, los colores, el borde y las flechas opcionales.

Interface 

@mixin button_style_arrow($attr: (
    width: 150px,
    height: 47px,
    aspect_ratio: null,
    bg: #FFF,
    bg_hover: #000,
    bg_active: #000,
    bg_disabled: color.adjust(#000, $lightness: 70%),
    color: #000,
    color_hover: #FFF,
    color_active: #FFF,
    color_disabled: color.adjust(#000, $lightness: 40%),
    border_radius: 0px,
    border: 1px solid #000,
    border_hover: 1px solid #000,
    border_active: 1px solid #000,
    border_disabled: 1px solid color.adjust(#000, $lightness: 70%),
    padding: 10px,
    tf: (),
    time: 500ms,
    position: (),
    icon: right,
    display: flex,
    cursor: pointer,
    cursor_disabled: not-allowed,
    reset: true
));
