Bienvenido a SISASS

SISASS, abreviatura de Simple Interface for SASS, es un framework orientado a construir interfaces de forma más organizada, reutilizable y escalable. Reúne variables, mixins, funciones y utilidades listas para acelerar el desarrollo de estilos en proyectos reales.

Esta documentación reúne la referencia de sus módulos principales, explica el propósito de cada archivo base y muestra ejemplos prácticos para entender cómo usar sus utilidades en contexto. La idea no es solo listar la API, sino ayudarte a integrar el framework y comprender la lógica detrás de cada herramienta.
