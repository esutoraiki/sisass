Bienvenido a SISASS

SISASS, abreviatura de Simple Interface for SASS, es un framework orientado a construir interfaces de forma más organizada, reutilizable y escalable. Reúne variables, mixins, funciones, clases silenciosas y utilidades listas para acelerar el desarrollo de estilos en proyectos reales.

Esta documentación reúne la referencia de sus módulos principales, explica el propósito de cada archivo base y muestra ejemplos prácticos para entender cómo usar sus utilidades en contexto. La idea no es solo listar la API, sino ayudarte a integrar el framework y comprender la lógica detrás de cada herramienta.

Si estás empezando, puedes recorrer las secciones de src para conocer la estructura general del framework y después revisar los ejemplos disponibles para identificar qué mixins, funciones o helpers se ajustan mejor a tu flujo de trabajo.
