media (_mediaqueries.scscs)

Tipo: Mixin

Versión: 2.x.x

Combina dimensiones, orientación, pantalla, interacción y preferencias del usuario mediante un único mapa. Las condiciones usan and de forma predeterminada y también admiten or.

Para negar el grupo completo usa la clave entre comillas "not", porque not es una palabra reservada en Sass. Las claves desconocidas y los valores incompatibles detienen la compilación.

Interface 

@mixin media($attr: ());
