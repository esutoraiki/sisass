mbr (_mediaqueries.scscs)

Tipo: Mixin

Versión: 2.x.x

Crea múltiples breakpoints de ancho usando una lista de puntos de corte. En cada iteración ejecuta el contenido recibido y entrega el índice actual mediante @content($i).

Es útil cuando varias propiedades cambian siguiendo listas paralelas de valores. Normalmente se combina con list.nth() para obtener el valor correspondiente a cada breakpoint.

Interface 

@mixin mbr($points...) using ($i);

Parámetros secuenciales

Parámetro Tipo Default Descripción
points Arglist - Define los puntos de corte usados para generar media queries de ancho.
i Number - Expone el índice actual del breakpoint dentro del bloque using.
